I break things to learn how they hold together. Then I build things that hold on their own.

I got into this because I got tired of software that breaks the moment you look away.

I build tools that are meant to be used, and I'm not precious about the stack. I use whatever solves the problem. A lot of it comes from fixing something that annoyed me, then going one step further than "it works."

Not everything here is polished or popular, a lot of it is honest "I made this because I needed it" work. That's fine, it gets better every time I touch it.

If any of it's useful to you, or you've got an idea in the same lane, open an issue or a PR. I read them.
